# [Fund Name] — One-Page Fund Website

A minimalist, premium one-page website designed for deployment on Vercel.

## Files

- `index.html` — site structure and content
- `styles.css` — complete responsive styling
- `script.js` — automatically updates the footer year

## Customize

Replace the following placeholders in `index.html`:

- `[Fund Name]`
- `[Insert 1 sentence thesis, e.g., Backing early-stage B2B software founders]`
- `[your-email@fund.com]`

To use real images, replace each `.image-placeholder` block with an `<img>` element or apply a background image in `styles.css`.

## Deploy to Vercel

1. Unzip the folder.
2. Upload the folder to a new GitHub repository, or import it directly into Vercel.
3. In Vercel, create a new project and select the repository.
4. No build command or framework preset is required.
5. Deploy, then add your custom domain under **Project Settings → Domains**.
